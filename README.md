# UX Rescue Squad

A mobile-friendly, single-file HCI learning game for GitHub Pages. Students learn by choosing design fixes in 23 short scenarios covering Nielsen’s 10 heuristics, Shneiderman’s 8 Golden Rules, and 5 usability qualities.

The first deck includes a guided, unscored practice mission. Each principle is defined on its mission card, and feedback explains why a choice works or falls short. Students can retry missed scenarios without changing their first-choice score, then review a recap showing which principles they mastered and which to revisit.

## Play

https://husseinhmahmood-star.github.io/HCIAPP/

## Run locally

Open `index.html` in a modern browser. The game has no server-side code, build step, account, or third-party assets. Best scores are stored only in the current browser on the player’s device.

## Publish

The repository’s GitHub Pages site is published from the `main` branch root.
